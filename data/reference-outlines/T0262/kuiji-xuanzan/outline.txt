# Conventions for every Kuiji chapter (controller decision, 2026-09-22):
# - A 品 node's children are its gate node(s) (三門分別 / 六門料簡 …, commentary-internal, the gates
#   as their children) and, when Kuiji announces a division of the chapter text itself (陀羅尼品

#   divisions are its children.
# - @exp = the line of the node's topic marker (此初 / 下明… / 第二… / …者; a 品's cb:mulu line);
#   @ann = the line of the parent's announcement; a sub-item Kuiji only lists has @ann = @exp.
# - Lemma divisions (經「A至B」) have @lemma + @basis=lemma; sub-items Kuiji lists without a lemma
#   have the annotator's @cut + @basis=manual (the compiler checks both against T09n0262).
# - When a node's topic marker (此初也 …) stands more than two lines after the 經 line that quotes its
#   lemma (Kuiji quotes the lemma once, then announces several levels), @exp stays the marker's line
#   and @lemsrc gives the 經 line (added in Task 5; the compiler checks the lemma there).

#   Flag truncated = the gold does not encode all of this node's source children (depth limit or
#   covered-span end); it keeps any announced @n, plus count_mismatch. Flag coarsened keeps the
#   schema's meaning (Kuiji himself stops subdividing a long span); no node of this gold carries it.
#   Scope: the coverage_span lines below (-> metadata.coverage_spans; spans inclusive; max_level =
#   absolute outline level, full = no limit) alone decide what is scored: a predicted node is in
#   scope iff its start locator (commentary.explained; in sūtra-mode root-text scoring,
#   root_text.start) lies in an entry's span and its level <= that entry's max_level. Start in span,
#   not whole span: an entry's root_text bounds the covered leaves, not every node's span (大文分二's
#   span runs to the end of 譬喻品). In-scope predictions that match no gold node are FP, also under a

#   descendants are scored normally and its unencoded source children are not FN; in this gold the

#   the out-of-scope predicted subtrees.

#   carries flag truncated; a comment next to it lists the children left out.
