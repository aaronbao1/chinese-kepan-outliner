# experiments/

Each experiment is a numbered folder `Enn-slug/`, started from [`_template/`](_template/README.md). Its README states the hypotheses and decision rules before anything is run; the result, the interpretation and any later addenda follow, dated. Code that more than one experiment needs lives in `pipeline/`; a folder keeps only its harness, its records (`metrics.json`, `looks*.json`, `projects.json`, `sanity.json`) and a `SUMMARY.md` of the numbers. Bulk outputs go in `out/` or `runs/`, which are gitignored and rebuilt by the harness.

> **Note (2026-10-05, clean copy):** the four records below are kept as written. Their references to planning notes, research threads (R-codes), NEXT_STEPS and the freeze tags point to the development repository and are not part of this copy. The numbers E02–E05, which the records mention, were reserved for experiments that have not been run.

In E06 and E07 the hybrid and model-only arms were answered by Claude Code subagents through the pipeline's `interactive` adapter, not through the `claude` API adapter, and each request was answered once. No experiment has scored a test span of T1718 or T1723, and no build has read one. One exposure is recorded: E07's model-only request for T0262 序品 showed 3 root-text lines of the test region and 1 of the reserve, unscored.

Reproducing: each harness (`run_e01.py`, `run_e06.py`, `run_e07.py`, and E00's `census.py`, `level1.py`, `x0231_leaves.py`) gives its commands and inputs in its docstring. The tier-1 and tier-2 arms rebuild from `data/raw/` alone (fetched as in [`../scripts/README.md`](../scripts/README.md)). The hybrid and model-only arms need the recorded model answers under the gitignored `runs/`, or a new answering pass. The leakage audits (`audit_leakage.py`) need the original Claude Code session transcripts, which are not in this repository.
